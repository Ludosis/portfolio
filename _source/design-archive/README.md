# Design Archive

Design studies for the 2026 redesign. These are self-contained HTML mockups —
open directly in a browser. Fonts are system approximations (the sandbox that
generated them can't load webfonts); production faces are noted on each page.

| File | What it is |
|------|-----------|
| `2026-07-design-directions.html` | Three-direction study: Drafting Table, Studio Dark, Field Notes. Same home-page content rendered in each visual language, with live canvas sketches of the shader-hero concept. |
| `2026-07-blend-drafting-lightbox.html` | The chosen direction candidate: Drafting Table chrome with blueprint-dark lightbox wells for all media. Includes a project-page media treatment sample. |

## Outcome

- **Drafting Table** was chosen as the base direction (user, July 2026).
- The **blend** (Drafting Table paper + blueprint wells for imagery) was mocked up
  for comparison against pure Drafting Table.
- Production type: Fraunces (display serif), IBM Plex Sans (body), IBM Plex Mono
  (annotations, figure captions, nav).
- Palette: bone `#F2EDE0`, ink `#211E18`, prussian `#29506D`, red pencil `#A6402A`,
  blueprint well `#10161B` (blend only).
